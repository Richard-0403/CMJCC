# Architecture Decision Records

Each ADR records a decision, its rationale, alternatives, and the impact on
evaluation. See the landing plan section 32 for the intended ADR list.

- ADR-001: Structured state vs pure agent memory
- ADR-002: CMJCC does not perform ranking
- ADR-003: Unknown-field policy for hard constraints
- ADR-004: Retrieval method and candidate-pool size
- ADR-005: Ranking features and weights
- ADR-006: Active-search overrides separated from long-term memory
- ADR-007: LLM failure fallback
- ADR-008: no-context ablation boundary
- ADR-009: Explanation claim validation
- ADR-010: Experiment artifacts and reproducibility
- ADR-011: PostgreSQL as the database (overrides SQLite in the landing plan)
