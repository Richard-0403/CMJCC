  固定职位目录快照、提示词、随机种子；基准日期 2026-01-01；top-k = 5。

## 3. 主要发现

1. 完整架构满足全部指定硬约束（HCSR = 1.00），且没有未被证据支持的事实性
   claim（grounding = 1.00，handoff 成功率 = 1.00）。
2. **职位上下文编排贡献最大**：移除后（no_context）HCSR 近乎减半（1.00 → 0.56），
   每个推荐职位平均新增约 0.875 个硬约束违规。
3. **候选人记忆在多轮场景中明显有效**：记忆依赖场景任务成功率 +0.44
   （McNemar p = 0.016）。
4. 效应集中出现在预期的子集（记忆依赖 / 上下文依赖），与各组件承担其设计职责的
   解释一致。

## 4. 局限性（论文需明确说明）

- **相关性由透明的自动 oracle 打分，而非人工评分者。** 因此
  NDCG@5 / Precision@5 / 平均分级相关性衡量的是与一个确定性规则参考的一致性，
  未报告评分者一致性（属于构念效度威胁）。已预留人工标注接口供真实评分者替换。
- **解释 grounding** 使用系统自带的 claim 校验器（supported / 全部事实性 claim），
  并非独立人工判断。
- 运行使用**确定性 mock LLM 后端**，因此重复运行结果完全一致（方差为 0）；
  接入真实模型并进行 ≥3 次有意义的重复运行属于后续工作。
- 合成职位目录规模较小、场景数量适中；结果不能外推到真实招聘效果。报告结论仅限
  于本实验配置。
- 最稳健、且不依赖 oracle 的证据是消融实验中带置信区间的 HCSR / 任务成功率差异。
