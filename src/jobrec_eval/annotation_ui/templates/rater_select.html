Who is annotating?

Pick your name from the registered rater pool. Your choice is stored in a signed, HTTP-only cookie so that every label you save is attributed to you.

This is attribution, not a login

There is no password and no access control. Several people share this annotation machine and the service only listens on the local loopback interface, so selecting a name answers "whose label is this?" and nothing more. Anybody sitting at this machine can pick any name in the list, so please pick your own, and use "Switch rater" when you hand the keyboard over.
